## 개요

단일 dotfiles 안에 뭉쳐 있던 Claude 스킬을 도메인별 마켓플레이스 repo 로 쪼개는
분리 작업이 주된 릴리즈입니다. 다섯 개의 스킬 repo 가 새로 생겼고 기존
`claude-plugin-visuals` 가 새 이름·새 레이아웃으로 옮겨 갔으며, 그 과정에서 드러난
대량 배치 스캔 버그와 플러그인 동기화 강제 실행 문제가 함께 정리되었습니다.

---

## 주요 변경사항

### 1. 스킬 마켓플레이스 분리 (#1410)

스킬이 이제 dotfiles 본체가 아니라 도메인별 독립 repo 에서 관리됩니다. 각 repo 는
자체 버전을 갖고 따로 설치·업데이트할 수 있습니다.

- **`harness-skills`**: 하네스별 도구 매핑과 공용 CI 워크플로를 한 곳에서 소유합니다. 도구 이름이 바뀌어도 열다섯 개 repo 를 각각 고치는 대신 한 번만 고치면 됩니다.
- **`devenv-skills` / `pkm-skills` / `notes-skills` / `gh-resolve-skills`**: 개발 환경, 개인 지식 관리, 문서 작성, GitHub PR 정리 스킬이 각각 자기 repo 를 갖습니다.
- **`visuals-skills`**: 기존 `claude-plugin-visuals` 가 새 이름과 루트 매니페스트 레이아웃으로 전환되어, Claude Code 외의 하네스에서도 스킬이 인식됩니다.
- 다섯 repo 전부가 dotfiles 의 등록 테이블과 회귀 테스트에 편입되어, 신규 repo 를 빠뜨린 채 병합하는 일이 막힙니다.

### 2. 플러그인 동기화 끄기

- **`DOTFILES_PLUGIN_SYNC_DISABLED`**: 플러그인 자동 동기화 훅을 환경변수 하나로 끌 수 있습니다. 동기화가 방해가 되는 작업 환경에서 훅을 지우지 않고 우회할 수 있습니다.

### 3. 대량 배치 스캔 안정화 (gcp-scan)

- 배치 규모가 커지면 Stage-1.6 검사가 무력화되던 문제를 고쳐, 큰 배치에서도 같은 검증이 적용됩니다.
- conflict 가 하나만 나도 배치 전체를 포기하던 동작을 바꿔, 나머지 항목은 정상 처리됩니다.
