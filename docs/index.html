notes-skills

끝낸 일을 글로 바꾸는 다섯 개의 스킬. 장애 분석, 재사용 패턴 노트, 릴리즈 노트, 일자별 작업 로그, 디버깅 삽질 블로그. notes 라는 하나의 플러그인으로 묶여 여섯 개의 코딩 에이전트 하네스에 설치됩니다.

5스킬
6지원 하네스
10문서 페이지
0.1.0플러그인 버전

스킬

각 스킬마다 설명서(visual guide)와 실제로 한 번 실행한 기록(usage example)이 있습니다. usage 문서의 경로·수치·산출물은 전부 실제 실행 결과입니다.

rca

Root Cause Analysis 보고서 작성

장애·버그·반복 실수 하나를 9개 섹션 고정 템플릿의 Jekyll 호환 마크다운 문서 한 개(YYYY-MM-DD-<slug>.md)로 산출합니다.

visual guide usage example

insight

대화에서 재사용 가능한 패턴 하나를 노트로

지금 나눈 대화에서 재사용 가능한 패턴 한 개를 뽑아, 현재 repo 의 docs/guide/learnings/ 에 50~80줄짜리 한국어 노트 한 개로 남기고 그 디렉터리의 색인까지 갱신합니다.

visual guide usage example

release-note

git 히스토리를 사용자 관점 릴리즈 노트로

두 릴리즈 사이의 git 커밋을 수집해, 커밋을 1:1로 나열하는 대신 사용자 관점 테마로 묶은 한국어 릴리즈 노트 문서를 산출합니다.

visual guide usage example

task-history

이번 세션의 작업을 일자별 로그에 기록

이번 대화에서 끝낸 작업을 일자별 로그 파일에 덧붙이고, 그대로 복사해 붙일 수 있는 JIRA 티켓 본문과 PR 설명 두 가지 형식을 함께 산출합니다.

visual guide usage example

blog-dev-learnings

삽질기를 읽히는 한국어 개발 블로그로

디버깅 삽질기·장애·기술적 함정 하나를 "고통 → 삽질 → 깨달음 → 해결" 서사를 따르는 7개 섹션짜리 한국어 블로그 글 파일로 산출합니다.

visual guide usage example

어느 것을 고를까

같은 사건이라도 남기는 문체가 다릅니다. 셋 중 하나를 고르는 것이지 셋을 다 돌리는 것이 아닙니다. 나머지 구분선은 파일이 어디에 떨어지는가입니다.

현재 repo 안에 씀바깥 절대 경로에 씀
insight -> docs/guide/learnings/rca -> $RCA_REPO_PATH
release-note -> 프로젝트의 기존 릴리즈 노트 관례task-history -> $TASK_HISTORY_DIR
blog-dev-learnings -> ~/para/archive/playbook/docs/dev-learnings/
